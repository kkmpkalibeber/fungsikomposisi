Konsep Dasar Fungsi Komposisi

Apa itu fungsi komposisi? Bayangkan Anda memiliki dua buah mesin pabrik yang bekerja secara berurutan. Mesin pertama ($g$) memproses bahan mentah menjadi setengah jadi, lalu mesin kedua ($f$) memproses hasil dari mesin pertama menjadi produk akhir. Penggabungan kerja dua fungsi ini disebut sebagai Fungsi Komposisi.

Fungsi Pertama g(x)
Fungsi Kedua f(x)
Hasil Komposisi (f ∘ g)(x) = f(g(x))

Notasi Pembacaan

Notasi (f ∘ g)(x) dibaca "f bundaran g dari x" atau "f komposisi g". Artinya, fungsi g dikerjakan terlebih dahulu terhadap x, kemudian hasilnya dimasukkan ke fungsi f.

Sifat-Sifat Penting

  • Umumnya tidak komutatif: (f ∘ g)(x) ≠ (g ∘ f)(x)
  • Bersifat asosiatif: (f ∘ (g ∘ h))(x) = ((f ∘ g) ∘ h)(x)
  • Terdapat fungsi identitas I(x) = x sehingga (f ∘ I)(x) = (I ∘ f)(x) = f(x)

Contoh 1: Fungsi Aljabar Biasa (Langkah demi Langkah)

Diberikan dua fungsi aljabar:

f(x) = 2x + 3      dan      g(x) = x² - 1

Tentukan rumus fungsi komposisi (f ∘ g)(x) dan hitung nilai untuk x = 3!

Penyelesaian Langkah 1: Memahami Definisi (f ∘ g)(x) = f(g(x))
Penyelesaian Langkah 2: Substitusi Fungsi g(x) ke dalam f(x)

f(x² - 1) = 2(x² - 1) + 3

= 2x² - 2 + 3

= 2x² + 1

Penyelesaian Langkah 3: Menghitung Nilai untuk x = 3

(f ∘ g)(3) = 2(3)² + 1 = 2(9) + 1 = 18 + 1 = 19

Contoh 2: Aplikasi Kontekstual di Masyarakat (Diskon Bertingkat)

Di sebuah pusat perbelanjaan, toko pakaian memberikan promo kupon diskon bertingkat. Seorang pembeli mendapatkan kupon diskon toko sebesar 20% dilanjutkan dengan potongan voucher member sebesar Rp 50.000.

Fungsi Pertama (Diskon 20%): f(x) = 0.8x

x adalah harga awal barang dalam Rupiah.

Fungsi Kedua (Potongan Voucher): g(x) = x - 50000

Potongan langsung Rp 50.000 dari harga setelah diskon.

Analisis Harga Akhir untuk Barang Sebesar Rp 400.000:

Jika kasir menerapkan diskon toko terlebih dahulu baru voucher (g ∘ f)(400000):

  • Harga setelah diskon 20%: f(400.000) = 0.8 × 400.000 = Rp 320.000
  • Harga setelah voucher: g(320.000) = 320.000 - 50.000 = Rp 270.000

Skor Anda: 0 / 100
Soal 1 dari 5

Diketahui fungsi f(x) = 3x - 1 dan g(x) = 2x + 4. Tentukan rumus fungsi komposisi (f ∘ g)(x)!

Pembahasan: (f ∘ g)(x) = f(g(x)) = 3(2x + 4) - 1 = 6x + 12 - 1 = 6x + 11 (Jawaban A).
Soal 2 dari 5

Jika f(x) = x² + 2 dan g(x) = x - 3, berapakah nilai dari (f ∘ g)(2)?

Pembahasan: g(2) = 2 - 3 = -1. Kemudian f(-1) = (-1)² + 2 = 1 + 2 = 3 (Jawaban A).
Soal 3 dari 5

Diketahui (f ∘ g)(x) = 4x² + 8x - 3 dan g(x) = 2x + 2. Tentukan rumus f(x)!

Pembahasan: Misal p = 2x + 2 maka x = (p-2)/2. Substitusi balik menghasilkan f(x) = x² - 5 (Jawaban D).
Soal 4 dari 5

Manakah pernyataan di bawah ini yang paling tepat mengenai sifat fungsi komposisi?

Pembahasan: Fungsi komposisi umumnya tidak komutatif, tetapi memenuhi sifat asosiatif (Jawaban B).
Soal 5 dari 5

Sebuah pabrik kertas menggunakan mesin I untuk mengubah kayu menjadi bubur kertas dengan fungsi f(x) = 2x - 1 (dalam ton), lalu mesin II mengubah bubur kertas menjadi kertas siap pakai dengan g(x) = x² + 5. Jika tersedia 3 ton kayu, berapa ton kertas akhir yang dihasilkan jika melalui mesin I lalu mesin II?

Pembahasan: f(3) = 2(3) - 1 = 5 ton bubur. Lalu g(5) = 5² + 5 = 25 + 5 = 30 ton (Jawaban B).
